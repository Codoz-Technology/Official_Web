## 🔍 **LINK PROSPECTING TECHNIQUES**

### **Method 1: Competitor Backlink Analysis**
```bash
# Using Ahrefs (Example queries)
1. Enter competitor domain in Ahrefs
2. Go to "Backlinks" section  
3. Filter by:
   - DR 30+ (Domain Rating)
   - Live links only
   - DoFollow links
   - English language
4. Export opportunities
5. Check relevance and contact info
```

### **Method 2: Content-Based Prospecting**
```bash
# Google Search Operators
"web development" + "write for us"
"AI solutions" + "guest post"  
"digital marketing" + "contribute"
intitle:"resources" + "web development"
intitle:"links we love" + technology
site:edu + "web development" + links
```

### **Method 3: HARO (Help A Reporter Out)**
**Daily Process**:
1. Check HARO emails 3x daily (morning, afternoon, evening)
2. Respond to 3-5 relevant queries daily
3. Template responses with expert insights
4. Include CodozTech credentials and contact info
5. Follow up on published articles

### **Method 4: Broken Link Building**
**Tools & Process**:
1. Use Ahrefs/SEMrush to find broken links on target sites
2. Create superior replacement content
3. Reach out with helpful broken link notification
4. Suggest your content as replacement
5. Follow up professionally
